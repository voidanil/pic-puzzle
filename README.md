# 🧩 Pic Puzzle

A web-based picture puzzle game where players select an image, shuffle it into pieces, and rearrange them to recreate the original picture.

## 🎮 Demo

👉 [Try Pic-Puzzle Online](https://pic-puzzle.vercel.app/)

## ✨ Features

- 🖼️ Select your own picture
- 🧩 Automatically shuffle the image into pieces
- 🎯 Drag and arrange pieces
- 🏆 Complete the picture to win
- 🔄 Restart or reshuffle the puzzle

## 🛠️ Built With

- HTML
- CSS
- JavaScript
